PLANETA HQ

Conecte a pasta do Google Drive onde estão suas HQs (PDF, CBZ) para montar sua biblioteca. Arquivos CBR não são exibidos, pois o app ainda não consegue lê-los.

Como conseguir isso?
  1. No Google Cloud Console, crie um projeto e ative a Google Drive API.
  2. Em "Credenciais", crie uma Chave de API e (recomendado) restrinja-a à Drive API.
  3. No Google Drive, clique com o botão direito na pasta raiz das HQs → Compartilhar → mude para "Qualquer pessoa com o link" → "Leitor". Isso é necessário para o app ler os arquivos sem exigir login de cada usuário.
  4. Abra a pasta no navegador; o ID é o trecho da URL depois de /folders/.
  5. Se ao abrir uma HQ der erro Failed to fetch, o navegador está bloqueando o download do conteúdo do arquivo por CORS (isso acontece com PDF/CBR mas não com a listagem, que é só metadado). Cole ali a URL de um Cloudflare Worker proxy — veja o texto abaixo do formulário para o código pronto.
  6. Cole os valores acima. Eles ficam salvos só neste dispositivo (não são enviados a nenhum servidor além do próprio Google e, se você configurar, do seu proxy).
